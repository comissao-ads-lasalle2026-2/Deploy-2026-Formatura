Dúvida Frequente: O Cartaz é físico impresso ou arquivo digital?

• Modelo Cartaz (FÍSICO OBRIGATÓRIO em mãos): Exige levar no dia 12/12 (Prova de Togas) uma folha impressa de tamanho A3 (29,7 x 42 cm) com até 6 fotos e frase. Pode ser feita no Canva e impressa em gráfica rápida ou ser uma colagem manual com fotos em cartolina. Não pode levar apenas no celular, pois o formando é filmado de toga segurando a folha física na frente do corpo.

• Modelo Árvore (100% DIGITAL): Não imprime nada, não compra folha A3 e não leva nada no dia das fotos. Você monta o arquivo JPG pelo celular ou computador e sobe diretamente no site da produtora até 24/01/2027. A produtora faz a animação no telão por computação gráfica.

📌 Como Atualizar o Portal Após Exportar o WhatsApp:
  1. No WhatsApp, vá em Mais opções (⋮) → Mais → Exportar conversa (Sem mídia) e salve o arquivo chat.txt ou chat.md na pasta Whats exportado/.
  2. No terminal do projeto, execute o script automatizado para extrair novidades e avisos:
python scripts/atualizar_portal.py

3. Em seguida, envie as alterações para o GitHub Pages:

git add . && git commit -m "update: novos avisos da formatura" && git push
